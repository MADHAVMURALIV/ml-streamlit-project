# Titanic Survival Prediction

A simple machine learning web application that predicts whether a passenger would have survived the Titanic disaster based on basic input features.

## Overview
This project uses a trained classification model to predict survival outcomes using passenger attributes.  
The application is built with Streamlit and provides an interactive interface for making predictions.

## Features
- Interactive web interface using Streamlit
- Predicts survival outcome (Survived / Did Not Survive)
- Uses a pre-trained machine learning model
- Simple and lightweight implementation

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- NumPy
- Joblib

## Project Structure
- `streamlitapp.py` – Streamlit web application
- `model.pkl` – Trained machine learning model
- `requirements.txt` – Project dependencies (if added)

## Input Features
- **Age** – Passenger age
- **Fare** – Ticket fare paid by the passenger

## Setup Instructions

pip install streamlit numpy scikit-learn joblib
